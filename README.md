## How to support the work

If a repository is useful, consider giving it a **GitHub star** so you can find it again and others can discover it. Specific bug reports, accessibility feedback and reproducible improvement suggestions are welcome through each project's **Issues** section.

**Important:** These are independent projects at different stages of maturity. Synthetic examples and documented tests must not be read as independent model benchmarks, commercial certifications or live-data guarantees. Public availability does not imply an open-source license: check each repository's terms before reuse.
